# Le Café des Ronrons — Lot Consommables 2 : Boissons froides

Ce lot contient six boissons froides validables en style 2D chibi pastel.

- `principaux/` : PNG transparents 640 × 640 pixels, affichage détaillé.
- `miniatures_menu/` : PNG transparents 256 × 256 pixels pour le pop-up de commande.
- `poses_sur_table/` : PNG transparents 384 × 384 pixels avec un sous-verre/soucoupe stylisé pour la commande servie.
- `planche_recapitulative_boissons_froides.png` : planche sur fond crème pour validation.
- `planche_originale_transparente.png` : visuel source avec les six boissons.
- `liste_assets.csv` : index des noms de fichiers et usages.

Les images n'ont pas encore été intégrées au site. Il s'agit du lot graphique à valider.
